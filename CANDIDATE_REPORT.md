# Summary

Проект приведён в рабочее состояние под WebGL: починены функциональные баги, ломавшие основной
игровой цикл (интерполяция движения, выталкивание игрока толпой, снаряды не засчитывали
попадания в упор), снят профиль в редакторе и в браузере, сделаны правки рендера с посчитанным
эффектом (−56% draw calls).

Главный вывод из браузерных замеров: **в WebGL-билде на целевом сценарии игра не упирается ни в
CPU, ни в GPU** — даже при 139 врагах кадр укладывается ровно в `requestAnimationFrame`
(p50=p95=p99=17.00 мс при 60 FPS). Поэтому оптимизация шла не «по списку подозрительного кода»,
а по статьям, где эффект был заранее посчитан и подтверждён замером.

минора между «до» и «после» обесценила бы сравнение)

**Browser:** Chrome/Chromium, desktop

**Hardware:** десктоп, канвас WebGL 1920×1080; редакторные замеры — на целевых 1920×1080,
уровень качества High (совпадает с `WebGL: 3`), vSync off. На этих настройках редактор

позволило переносить выводы между средами.

# Issues Found

Полный список — 43 находки в `docs/reports/01_ISSUES.md`. Ключевые:

- **Интерполяция Rigidbody не работала** — 80.3% кадров при 250 FPS рендерились с нулевым
  смещением (`MovePosition` на некинематическом теле + запись `transform.rotation` каждый кадр
  гасили интерполяцию)
- **Игрока выталкивало толпой** за пределы арены — скорость не обнулялась, импульсы депенетрации
  от 140 врагов копились
- **#40: снаряды не засчитывали попадания в упор** — `FirePoint` рождался внутри капсул врагов,
  `OnTriggerEnter` не приходил; плато счётчика убийств 24 секунды
- **Счёт переживал рестарт** (`static` поле), подписчики на `GameEvents` копились без `OnDisable`
- **Прямой запуск сцены `Game` падал** — зависимости резолвились через `FindObjectOfType`, `null`
  без `Boot`
- Мелкие: смерть не наступала при ровно 0 HP; снаряды взаимно самоуничтожались при столкновении
- **GC:** конкатенация строк в HUD каждый кадр (ребилд Canvas), `Resources.Load` на каждое
  попадание без папки `Resources`, `new WaitForSeconds` в цикле спавна
- **Рендер:** 468 draw calls при 140 врагах, забатчено 0, инстансировано 0

# Changes Made

11 файлов кода, два поля в ассетах, одна настройка Player Settings, одна галка в матрице слоёв:

- `PlayerController` — движение через `linearVelocity`, поворот через угловую скорость вокруг Y
- `Projectile` — разбор перекрытия через `OverlapSphereNonAlloc`, кеш `Resources.Load`
- `CameraFollow` — сглаживание независимо от частоты кадров
- `GameManager` — счёт из `static` в поле экземпляра, добавлен `OnDisable`, null-проверки
- `HUDController` — текст трогается только при изменении значения
- `PlayerHealth` — `<= 0` вместо `< 0`
- Кеш `PlayerHealth`, `Camera.main`, переиспользование `WaitForSeconds`
- `Enemy.prefab` — тени сняты; `Enemy.mat` — GPU Instancing включён
- Матрица слоёв — выключена пара `Projectile ↔ Projectile`
- Player Settings — включён `Decompression Fallback`

# Remaining Issues

Оставлено сознательно, с обоснованием в отчёте (`01_ISSUES.md`, `10_RENDER.md`):

- **Рейкасты врагов (#4)** — 9.6% main thread, но кадр и так укладывается с запасом; батчинг
  через `RaycastCommand` — заметная переделка ради статьи, которая не является узким местом
- **Физика врагов (#5)** — тела спят (`Active Dynamic Bodies=1` из 141), контактов нет
- **Пулинг объектов (#6)** — GC в билде почти не работает (0.09 сборок/с), проблема не проявляется
- **Managed Stripping / Stack Trace** — влияют на размер билда, меряются только сборкой, не
  трогал вслепую
- Стены арены ниже линии огня — не ломает функционально, правка уровневая

Не измерено: время загрузки, размер билда «до» правок, Unity Profiler в подключённом режиме
к WebGL, причина одного выброса 1695 мс из 900 кадров (гипотеза — потеря фокуса вкладки).

# What I Would Do Next

1. Снять «до» в браузере с коммита до правок — сейчас честное сравнение есть только в редакторе
2. Подключить Unity Profiler к development-билду для разбивки по функциям под vSync-локом
3. Измерить размер билда при `Managed Stripping Level = Medium`, с полным ретестом геймплея
4. Снять тени со снарядов/эффектов, пометить статичную геометрию арены как Static
5. Усилить стресс-сценарий — текущий не является тяжёлой нагрузкой (60 FPS с запасом)
6. Техдолг вне рамок задания: `GameManager` как god-объект, сервисы как MonoBehaviour,
   отсутствие стейт-машины у врагов
